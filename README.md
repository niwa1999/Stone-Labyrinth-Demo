# SIGIL ABYSS（シジル・アビス）
旧タイトル：石の迷宮 / formerly Stone Labyrinth

3DダンジョンRPG『SIGIL ABYSS』。
明かりを携えて迷宮へ潜り、敵と戦い、戦利品を持ち帰る冒険をお楽しみください。

## 無料体験版54D
[GitHubのダウンロードページ](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54D-magic-20261102)

バンシー編・ヴァリアド編・遺跡篇（地下4階まで）の3シナリオを収録。
54Dでは、魔法の形と動きを炎・氷・雷・土・風・水・毒・闇・光・回復などで作り分けました。範囲魔法とブレスにも違いを追加。54Bの滑らかな移動・向き直りと54Cの白狼などの輪郭読み込みによる終了の修正も含みます。戦闘計算や保存形式は維持しています。

AssetsのZIPをすべて展開し、`SigilAbyss_Demo.exe`を起動してください。
Windows 64bit／Direct3D 11／キーボード操作。
日本語・英語・ポルトガル語（ブラジル）対応。一部未翻訳があります。

地上：矢印／テンキーで施設選択、Enter／Eで利用。I持ち物／W装備／C能力／J番号コマンド／Kメッセージ別窓／L履歴／Ctrl＋S索敵／Shift＋S隠密／F1ヘルプ。

保存先は `%LOCALAPPDATA%\StoneDungeonDemo`。旧体験版のセーブを読み込めます。更新前にセーブと関連ファイルを保管してください。保存形式101で保存したデータは旧版では読めません。体験版から製品版への移行は非対応です。

## English
[Demo 54D — download page](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54D-magic-20261102)
A 3D dungeon RPG. Explore with your light, fight enemies and bring home loot. Three scenarios including the Ancient Ruins (four floors). 54D adds distinct elemental spell shapes and motion, area magic and breath effects. Includes smoother movement and the legacy enemy-outline crash fix. Extract all files and run SigilAbyss_Demo.exe. Windows 64-bit / Direct3D 11 / keyboard. Japanese, English and Brazilian Portuguese (some text untranslated). Older demo saves supported; format 101 saves cannot be loaded by older versions. Back up saves. No demo-to-full transfer. Full version: [itch.io](https://niwa-1999.itch.io/sigil-abyss).

## Português (Brasil)
[Demonstração 54D — página de download](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54D-magic-20261102)
RPG de exploração de masmorras 3D. Explore com sua luz, enfrente inimigos e volte com os tesouros. Três cenários até as Ruínas Antigas (quatro andares). 54D diferencia formas e movimentos das magias, efeitos de área e sopros. Inclui movimento mais suave e correção do encerramento por contornos de imagens antigas. Extraia tudo e execute SigilAbyss_Demo.exe. Windows 64 bits / Direct3D 11 / teclado. Japonês, inglês e português brasileiro (alguns textos não traduzidos). Aceita dados antigos; dados no formato 101 não funcionam em versões anteriores. Faça backup. Sem transferência para a versão completa. Versão completa: [itch.io](https://niwa-1999.itch.io/sigil-abyss).

Source code (zip / tar.gz) is not the playable game.

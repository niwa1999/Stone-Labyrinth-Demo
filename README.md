# SIGIL ABYSS（シジル・アビス）

3DダンジョンRPG『SIGIL ABYSS』。
明かりを携えて迷宮へ潜り、敵と戦い、戦利品を持ち帰る冒険をお楽しみください。

## 無料体験版55I
初心者迷宮と本編3シナリオ（バンシー篇・ヴァリアド篇・遺跡篇、遺跡B4まで）を収録。

▼ [体験版のダウンロードページ](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-55I-scenery-20261106)

55Iでは、迷宮に崩落跡・野営跡・女神像などの小物を地形に合わせて配置しました。骨は単独でも見つかります。剣と盾の一人称表示も調整しました。

J：数字キー登録／J→P：職業別プリセット／Shift＋J：小依頼・探索手帳／Shift＋T：消灯／T：再点灯／Ctrl＋S：100ターンの索敵／Shift＋S：隠密。

ZIPをすべて展開し、**SigilAbyss_Demo.exe**を起動してください。
Windows 64bit／Direct3D 11／キーボード操作。
日本語／英語／ポルトガル語（ブラジル）対応（一部未翻訳）。

旧体験版のセーブは読み込めます。保存形式104は54F以前では読めません。更新前にセーブと関連ファイルをバックアップしてください。体験版から製品版へのセーブ移行は非対応です。

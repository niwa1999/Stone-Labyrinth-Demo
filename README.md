# SIGIL ABYSS（シジル・アビス）
旧タイトル：石の迷宮 / Formerly Stone Labyrinth

## 体験版50R（2026年10月27日）
[体験版ZIPをダウンロード](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/download/demo-50R-adventure-20261027/SigilAbyss_Demo_50R_Windows_x64.zip) / [更新内容](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-50R-adventure-20261027)

すべて展開して `SigilAbyss_Demo.exe` を起動してください。Windows x64 / Direct3D 11 / キーボード操作。
バンシー編・ヴァリアド編の2シナリオを収録。50Rでは装備比較の要約、保護/売却候補指定、一括売却、新規装備の性能分岐、寄り道の報酬、帰還時の成果画面を追加しました。

持ち物でP：保護、B：売却候補。店の売却画面でT：一括売却、Enter：確定、Esc：取消。地上でF8：帰還記録を再表示。
I持ち物／W装備／C能力、Ctrl＋S索敵、Shift＋S隠密、F1ヘルプ、F2設定。
**保存形式94。旧体験版のセーブは読み込めますが、50Rで保存後は旧版では読めません。更新前のセーブを保管してください。** 保存先は `%LOCALAPPDATA%\StoneDungeonDemo` のまま。FULL版へのセーブ移行は非対応です。

日本語・英語・ポルトガル語（ブラジル）対応。固有名・長文台詞には未翻訳部分があります。謝辞・更新履歴・ライセンスを同梱。
[全シナリオを収録したFULL版はitch.ioで入手できます](https://niwa-1999.itch.io/sigil-abyss)。GitHubにはデモ版のみ公開しています。

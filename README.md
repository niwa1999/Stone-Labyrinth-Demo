# SIGIL ABYSS（シジル・アビス）

3DダンジョンRPG『SIGIL ABYSS』。
明かりを携えて迷宮へ潜り、敵と戦い、戦利品を持ち帰る冒険をお楽しみください。

## 無料体験版54Q
初心者迷宮と、本編のバンシー篇・ヴァリアド篇・遺跡篇（遺跡B4まで）を収録。

▼ [体験版のダウンロードページ](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54Q-first-person-20261103)

54Qでは、武器と盾を持つ手を一人称で表示するようになりました。攻撃・弓射撃・盾バッシュの動き、素材と照明を追加しています。F2→表示→「武器・盾・手の表示」でオン／オフを選べ、設定は次回起動後も残ります。

数字キーの登録表を画面下へ戻し、持ち物・装備・ステータスを全画面表示にしました。固有の★アーティファクトの誤売却も防止します。

Shift＋Ctrl：盾を構える／Shift＋Ctrl＋↑・テンキー8：盾バッシュ（MP/SP3）／J：数字キー登録／J→P：職業別プリセット／Shift＋J：小依頼・探索手帳／Shift＋T：消灯／T：再点灯／Ctrl＋S：100ターンの索敵／Shift＋S：隠密。

ZIPをすべて展開し、**SigilAbyss_Demo.exe**を起動してください。
Windows 64bit／Direct3D 11／キーボード操作。
日本語／英語／ポルトガル語（ブラジル）対応（一部未翻訳）。

旧体験版のセーブは読み込めます。保存形式104は54F以前では読めません。更新前にセーブと関連ファイルをバックアップしてください。体験版から製品版へのセーブ移行は非対応です。

## English
[Download the 54Q demo](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54Q-first-person-20261103). Includes the beginner dungeon and three scenarios through Ancient Ruins B4. New first-person weapon/hand/shield animations, worn materials and lighting. Toggle the view in F2 > Display; combat remains unchanged. The number-key shortcut bar returns and inventory/equipment/status use full-screen pages. Extract everything and run SigilAbyss_Demo.exe. Windows 64-bit / Direct3D 11 / keyboard. Japanese, English and Brazilian Portuguese (some untranslated text). Older demo saves load; format 104 cannot be read by 54F or earlier. Back up saves and related files. No demo-to-full save transfer. [Full version on itch.io](https://niwa-1999.itch.io/sigil-abyss).

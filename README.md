# SIGIL ABYSS（シジル・アビス）
旧タイトル：石の迷宮 / formerly Stone Labyrinth

3DダンジョンRPG『SIGIL ABYSS』。
明かりを携えて迷宮へ潜り、敵と戦い、戦利品を持ち帰る冒険をお楽しみください。

## 無料体験版54E
[GitHubのダウンロードページ](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54E-quick-commands-20261102)

バンシー編・ヴァリアド編・遺跡篇（地下4階まで）の3シナリオを収録。

54Eでは数字キーに道具だけでなく、習得済みの魔法・技能・コマンドを登録できます。Jで編集、J→Pで職業別プリセットを確認し、空き枠へ登録できます。既存の設定は上書きしません。
共通配置は1＝鑑定済み回復薬、2＝明かり、3＝よく使う行動。狩人の3は狙い撃ち、召喚士の3は小精霊召喚、0は契約・使役。通常の装備・矢・SP/MP・射程や対象確認は維持しています。ヘルプ・宿屋の情報にも使い方を追加しました。54Dの属性別魔法演出も収録しています。

AssetsのZIPをすべて展開し、`SigilAbyss_Demo.exe`を起動してください。
Windows 64bit／Direct3D 11／キーボード操作。
日本語・英語・ポルトガル語（ブラジル）対応（一部未翻訳）。
I持ち物／W装備／C能力／J番号コマンド／Kメッセージ別窓／L履歴／Ctrl＋S索敵／Shift＋S隠密／F1ヘルプ。

旧体験版のセーブを読み込めます。保存先は `%LOCALAPPDATA%\StoneDungeonDemo`。更新前にセーブと関連ファイルを保管してください。**54Eで保存した形式102のデータは54D以前では読めません。** 体験版から製品版への移行は非対応です。

## English
[Demo 54E — download page](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54E-quick-commands-20261102)
A 3D dungeon RPG. Explore with your light, fight enemies and bring home loot. Three scenarios through Ancient Ruins B4. 54E adds number-key bindings for spells, skills and commands, plus job presets via J then P. Common slots: 1 identified healing potion, 2 lighting, 3 main action. Hunters: Aimed Shot. Summoners: small-spirit placement on 3 and contracts/commands on 0. Preserves existing bindings and normal combat rules. Includes 54D elemental spell effects. Extract all files and run SigilAbyss_Demo.exe. Windows 64-bit / Direct3D 11 / keyboard. Japanese, English and Brazilian Portuguese (some untranslated text). Older demo saves supported; format 102 saves cannot be loaded by 54D or earlier. Back up saves before updating. No demo-to-full transfer. Full version: [itch.io](https://niwa-1999.itch.io/sigil-abyss).

## Português (Brasil)
[Demonstração 54E — página de download](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54E-quick-commands-20261102)
RPG de exploração de masmorras 3D. Explore com sua luz, enfrente inimigos e volte com os tesouros. Três cenários até as Ruínas Antigas B4. 54E registra magias, técnicas e comandos nas teclas numéricas; J e P mostram a predefinição da classe. 1: cura identificada, 2: luz, 3: ação principal. Caçadores: Tiro Mirado. Invocadores: espírito menor no 3, contratos/comandos no 0. Preserva registros e regras normais de combate. Inclui os efeitos elementais de 54D. Extraia tudo e execute SigilAbyss_Demo.exe. Windows 64 bits / Direct3D 11 / teclado. Japonês, inglês e português brasileiro (alguns textos não traduzidos). Aceita dados antigos; dados no formato 102 não funcionam em 54D ou anteriores. Faça backup antes de atualizar. Sem transferência para a versão completa. Versão completa: [itch.io](https://niwa-1999.itch.io/sigil-abyss).

Source code (zip / tar.gz) is not the playable game.

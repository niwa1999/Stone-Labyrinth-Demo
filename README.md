# SIGIL ABYSS（シジル・アビス）

3DダンジョンRPG『SIGIL ABYSS』。明かりを携えて迷宮へ潜り、敵と戦い、戦利品を持ち帰る冒険をお楽しみください。

## 無料体験版54G
初心者迷宮と、本編のバンシー篇・ヴァリアド篇・遺跡篇（B4まで）の3シナリオを収録。後半シナリオ・深層は体験版に含みません。

▼ [体験版のダウンロードページ](https://github.com/niwa1999/Stone-Labyrinth-Demo/releases/tag/demo-54G-guild-adventures-20261102)

54Gでは地下2層の初心者迷宮、F～Sの冒険者ランク、小依頼の掲示板、手記・台座・壁の刻印から始まる探索依頼、食料や油を売る行商人を追加しました。難易度と推奨レベルを確認でき、依頼報酬は金銭と物資です。既にバンシー篇を受注した方は最低E、遺跡篇を受注した方は最低Dとして継続できます。

Shift＋J：小依頼・探索手帳／E：調査・取引／Shift＋T：消灯／T：再点灯／Ctrl＋S：100ターンの索敵／Shift＋S：隠密。Jの数字キー登録・職業別プリセットも引き続き使えます。

ZIPをすべて展開し、**SigilAbyss_Demo.exe**を起動してください。
Windows 64bit／Direct3D 11／キーボード操作。日本語／英語／ポルトガル語（ブラジル）対応（一部未翻訳）。
旧体験版のセーブを読み込めますが、54Gで保存した形式104のデータは54F以前では読めません。更新前にセーブと関連ファイルをバックアップしてください。体験版から製品版へのセーブ移行は非対応です。

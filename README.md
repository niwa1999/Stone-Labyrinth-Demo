ZIPをすべて展開し、`SigilAbyss_Demo.exe`を起動してください。
Windows 64bit／Direct3D 11／キーボード操作。日本語・英語・ポルトガル語（ブラジル）対応。一部未翻訳があります。
地上：矢印／テンキーで施設選択、Enter／Eで利用。I持ち物／W装備／C能力／J番号コマンド／Kメッセージ別窓／L履歴／Ctrl＋S索敵／Shift＋S隠密／F1ヘルプ。
